# personal-site

Source for my personal website, built with [Zola](https://www.getzola.org/).

## Requirements

Zola 0.23.6. The version is pinned: use the same one locally and in CI.

## Commands

- `zola serve`: live preview at http://127.0.0.1:1111
- `zola build`: build the site into `public/`
- `zola check`: build without writing output and check all links
